# Vite + PHP Boilerplate

A minimal boilerplate enhancing **Vite** with **PHP** for lightweight server-side rendering and modern frontend tooling. Ideal for modular static sites that benefit from dynamic markup, meta tags, and production-optimized output.

## Features

- ⚡ Vite for fast development & bundling
- 🐘 PHP backend for:
  - Dynamic metadata injection
  - Server Side Markup sanitization/minifcation
  - Partials support for modular markup
- 🎯 Production builds:
  - Bundles and minifies JS
  - Purges unused CSS with PurgeCSS ( scans scss/js/html/php )
- 💅 Integrated SCSS Flexbox Grid system
- 🔁 Automatic reload on file changes (PHP + JS + SCSS)
